# 롤 코치 (AI 음성 코칭 + 판단 리플레이)

챌린저·프로 경기 데이터를 학습한 AI 코치가 게임 중에 음성으로 콜을 주고, 음성으로 질문하면 대답하고,
경기 후에는 "챌린저라면 이 순간 어떻게 했을지"를 장면별로 보여줍니다.

## 무엇을 하나
| 기능 | 내용 |
|---|---|
| 실시간 콜 | 2·3·6레벨 선점/뒤처짐, 솔킬·킬·데스, 맞라이너 사망, 귀환 골드(다음 코어템 완성 가능), 드래곤·바론 1분 전, 10·15분 CS 체크, 상대 아이템 완성 |
| AI 판단 | 솔킬 직후, 게임 시작 플랜, 질문할 때 → Claude가 현재 게임 상태 + 챌린저 장인 통계 + 라인전 원칙으로 판단 |
| 음성 대화 | 폰/PC 브라우저에서 "누르고 말하기" 또는 핸즈프리("코치, 솔킬 땄는데 지금 집 가면 라인 걸쳐지는데 어떻게 해?") → 답을 문장 단위로 바로 읽어줌. 이어서 질문 가능 |
| 학습 | 챌린저·그마 랭커 + 직접 넣은 프로 계정의 솔랭 경기와 분 단위 타임라인을 수집 → 챔피언마다 판수·승률·LP·프로 여부로 "장인" 상위 N명 선정 → 그들 사이의 합의(중앙값, 최빈값과 일치율)만 정답으로 사용 |
| 판단 리플레이 | 게임 중 콜·질문·답변이 시간별로 저장됨. 경기 후 라이엇 API로 내 경기를 받아 장인 합의와 지표 비교 + 핵심 순간마다 "내 플레이 / 챌린저라면 / 이유". 롤 리플레이를 열어두면 버튼으로 그 장면으로 이동 |

## 설치 (Windows PC, 롤 깔린 컴퓨터)
1. [Python 3.11+](https://www.python.org/downloads/) 설치 (설치 화면에서 "Add to PATH" 체크)
2. 이 폴더에서 `pip install -r requirements.txt`
3. `python -m lolcoach` 실행 → 화면에 나온 주소로 접속
   - PC: `https://localhost:8443`
   - 폰: `https://PC의IP:8443` (같은 와이파이). 처음엔 "안전하지 않음" 경고 → 고급 → 계속 (마이크를 쓰려면 HTTPS가 필요해서 자체 인증서를 씀)
4. 설정 탭에서 입력
   - **Claude API 키**: https://console.anthropic.com
   - **라이엇 API 키**: https://developer.riotgames.com (개발 키는 24시간마다 재발급)
   - **내 라이엇 ID**: `닉네임#KR1`
   - **프로 계정**(선택): 따라 하고 싶은 프로의 솔랭 계정. 가중치를 더 받음
5. 학습 탭 → 주 챔피언 이름(영어, 예: `Ahri`)을 넣고 학습 시작. 개발 키는 2분에 100회 제한이라 600회 기준 약 12분. 여러 번 돌릴수록 정확해짐
6. 롤 게임 시작하면 자동으로 "게임 중"으로 바뀌고 코칭 시작

음성은 크롬(안드로이드/PC) 기준. 소리는 한 기기에서만 나게 "이 기기에서 소리"를 하나만 켜두세요.

### 리플레이 장면 이동 켜기
`C:\Riot Games\League of Legends\Config\game.cfg` 의 `[General]` 아래에 `EnableReplayApi=1` 추가 → 롤 클라이언트에서 해당 경기 리플레이 열기 → "리플레이에서 보기" 버튼.

### 롤 없이 테스트
창 두 개에서 `python -m lolcoach mock` 과 `python -m lolcoach` 실행 → 아리 vs 제드 가짜 게임이 10배속으로 진행됨.

### 명령어
- `python -m lolcoach learn Ahri` — 터미널에서 학습
- `python -m lolcoach bench Ahri --vs Zed` — 학습된 합의 통계 보기
- `pytest` — 테스트

## 알아둘 점 (솔직하게)
- **라이엇 정책**: 게임 중 행동을 지시하는 서드파티 앱은 라이엇 개발자 정책 위반으로 볼 수 있고 계정 제재 위험이 있습니다. 쓰는 데이터는 라이엇 공식 Live Client API(내 화면·스코어보드에 보이는 정보만)라서 안 보이는 정보를 쓰지는 않지만, 랭크에서 실시간 콜은 본인 판단으로 쓰세요. 일반·연습 게임과 경기 후 리뷰는 안전한 쪽입니다. "실시간 음성 콜" 스위치로 끌 수 있습니다.
- **코치가 못 보는 것**: 미니언 웨이브 위치, 적 정글 위치, 적 스펠 쿨타임은 라이엇 API가 주지 않습니다. 그래서 그게 판단을 가르면 "웨이브가 상대 쪽이면 A, 내 쪽이면 B"처럼 조건을 걸어 답하도록 했습니다. CS는 라이엇 API가 10개 단위로만 갱신합니다.
- **"항상 정답"은 불가능**: 여러 장인의 합의로 한 사람의 버릇을 걸러내고, 숫자는 학습 데이터에 있는 것만 말하게 했지만 상황마다 정답이 갈리는 경우는 있습니다. 그럴 땐 일치율이 낮게 나오고 코치도 "갈린다"고 말합니다.
- **프로 대회 경기**: 라이엇 공식 API로는 대회 경기 타임라인을 받을 수 없어서, 프로는 솔랭 계정(설정에서 등록)으로 학습합니다. 한국 챌린저 랭커에는 프로 부계정이 많이 섞여 있습니다.
- **영상 분석 아님**: 리플레이 영상(.rofl)을 AI가 보는 게 아니라, 라이엇 경기 타임라인(1분 단위 위치·골드·CS, 킬/구매/와드 이벤트)으로 분석합니다.
- 오브젝트 시간(드래곤 5분, 바론 20분)은 패치마다 바뀔 수 있어서 `lolcoach/knowledge.py`의 `OBJECTIVES`에서 고칠 수 있습니다.

## 구조
| 파일 | 역할 |
|---|---|
| `lolcoach/state.py` | Live Client API 응답 → 게임 상태 (나, 맞라이너, 아군/적군) |
| `lolcoach/triggers.py` | 상태 변화에서 코칭할 순간 감지 |
| `lolcoach/coach.py` | 콜 우선순위·간격 조절, Claude 질문/대답(스트리밍 → 문장별 음성), 경기 기록 |
| `lolcoach/learn.py` | 챌린저/프로 경기 수집, 지표 추출, 장인 선정과 합의 통계 |
| `lolcoach/review.py` | 경기 후 리뷰 (장인 대비 비교 + 장면별 챌린저라면) |
| `lolcoach/knowledge.py` | 라인전 원칙 플레이북, 답변 규칙 |
| `lolcoach/llm.py` | Claude 연결 (claude-opus-5-5, 게임 중 effort low / 리뷰 high) |
| `lolcoach/server.py`, `web/index.html` | PC 서버 + 폰/PC 화면 |
| `lolcoach/mock.py` | 롤 없이 테스트하는 가짜 게임 |

키·학습 데이터·경기 기록은 `내 사용자 폴더/.lolcoach/` 에 저장되고 깃에는 올라가지 않습니다.
